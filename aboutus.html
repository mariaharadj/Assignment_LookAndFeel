About MotoTrack

MotoTrack is a student-developed website designed to demonstrate how web technologies can organize, manage, and visualize motorcycle-related information.

The website allows users to explore sample motorcycle records, perform basic record-management operations, and view charts comparing motorcycle categories and illustrative prices.

About the Developer

I am a student in the Application Development course (ISM 6225). I created MotoTrack as an opportunity to practice building a user-friendly website using HTML, CSS, and JavaScript.

During this project, I worked on structuring webpages, creating consistent navigation, styling responsive layouts, building interactive forms, and presenting data through visualizations. The project helped me understand how these technologies work together to create a functional web interface.

Technologies Used

HTML5

Structures the content and elements on each webpage.

CSS3

Creates the layout, colors, styling, and responsive design.

JavaScript

Supports interactive forms and motorcycle record operations.

Chart.js

Creates charts for the motorcycle analytics dashboard.

GitHub

Stores and manages the website's source code.

Project Scope

MotoTrack uses illustrative sample data to demonstrate website functionality. It is a static educational project and does not connect to a live motorcycle database or store records permanently.

The project demonstrates how a future data-driven motorcycle application could support information management and basic comparisons.
